# Playing Cards Layout

A clean, CSS-styled webpage displaying a collection of classic playing cards (Ace, King, and Jack across Hearts, Spades, and Clubs) built using pure HTML and CSS.

## Features
* **Custom Card Structure:** Each card is divided into three sections (`left`, `middle`, and `right`) to mimic real playing card corners and center symbols.
* **Suit & Color Styling:** Includes classic card suits (`♥`, `♠`, `♣`) with dedicated `.black` and default suit styling.
* **Responsive Card Grid:** Displays multiple playing cards neatly aligned inside the `#playing-cards` main container.

## Technologies Used
* **HTML5:** Semantic `<header>`, `<main>`, and structured `<div>` elements with Unicode card suit symbols.
* **CSS3:** Flexbox layout, card borders, shadows, and alignment classes (`left`, `middle`, `right`).

## Project Structure
```text
├── index.html      # Main HTML structure for the playing cards
├── styles.css      # Styling for card layout, colors, and alignment
└── README.md       # Project documentation
```

## How to Run
1. Download or clone this repository to your local machine.
2. Open the `index.html` file in any web browser.
